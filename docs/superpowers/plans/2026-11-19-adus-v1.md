# Adus v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun Adus v1: platform AI code review self-hosted (bot `@adudu`) untuk Azure DevOps Services dan GitHub via PAT, dengan dashboard untuk repo/connection, AI provider multi-key, rules & memory, user management, dan token usage.

**Architecture:** Satu binary Rust (`adus`) menjalankan API dashboard (axum), endpoint webhook, dan worker review dalam satu proses tokio. Postgres menyimpan semua data; Redis Streams menjadi antrian job. Dashboard SvelteKit SPA (`adapter-static`) + shadcn-svelte di-embed ke binary.

**Tech Stack:** Rust stable (edition 2024), tokio, axum, sqlx (Postgres), redis-rs, reqwest, serde, tracing, thiserror, async-trait, argon2, aes-gcm, similar, globset, rust-embed, clap (subcommand), wiremock (test). Deploy: Docker, Compose v2 (profiles), Caddy (opsional), GitHub Actions + GHCR. Frontend: SvelteKit + Svelte 5, Tailwind v4, shadcn-svelte, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-19-adus-design.md`

## Global Constraints

- Bot dipanggil `@adudu`; project/binary bernama `adus`. Lisensi AGPL-3.0.
- Provider git v1: Azure DevOps **Services** (`https://dev.azure.com/{org}`, REST `api-version=7.1`) dan GitHub (`https://api.github.com`), keduanya PAT.
- Infra: hanya `adus` + Postgres 16 + Redis 7. Tidak ada MongoDB/RabbitMQ.
- **Tidak membuka** `libs/ee/**` atau file `*.ee.*` dari Kodus (spec 6.13). Kode Kodus lain hanya referensi perilaku, tidak di-port.
- Rahasia (PAT, API key) dienkripsi AES-256-GCM dengan `ADUS_SECRET_KEY` (32 byte, base64). API tidak pernah mengembalikan nilai rahasia — hanya `*_last4` dan status.
- Password: argon2. Session cookie `adus_session` (`HttpOnly`, `SameSite=Lax`, `Secure` jika `ADUS_PUBLIC_URL` https), TTL 30 hari, disimpan di Postgres (hash SHA-256 token, bukan token mentah).
- Role: `admin` | `user`. Matriks hak akses = spec 6.7. Minimal satu admin aktif selalu ada.
- Komentar yang diposting Adus selalu memuat penanda `<!-- adudu -->`; komentar dengan penanda itu diabaikan.
- Perintah v1 hanya `@adudu review` dan `@adudu remember: <isi>` (case-insensitive); hanya dari user Adus terdaftar dan tidak disabled. Penulis tak terdaftar diabaikan tanpa balasan.
- Path file di dalam Adus selalu dinormalisasi **tanpa** `/` di depan (Azure mengembalikan `/src/a.rs`); tambahkan kembali `/` hanya saat memanggil API Azure.
- Retry job: maks 5 percobaan, backoff eksponensial (base 10 dtk), lalu ke stream `adus:jobs:dead`.
- Query DB pakai fungsi runtime `sqlx::query`/`query_as` + `#[derive(FromRow)]` (bukan macro `query!`), supaya build tidak butuh DB.
- Kode untuk pemula Rust: tidak ada macro buatan sendiri; trait hanya untuk `GitProvider`, `GitProviderFactory`, `LlmClient`, `ChatService` (masing-masing punya implementasi asli + fake untuk test).
- Format error API: `{"error":{"code":"<snake_case>","message":"<teks>"}}`. Semua endpoint dashboard di bawah `/api/v1`.
- Env: `DATABASE_URL`, `REDIS_URL`, `ADUS_SECRET_KEY`, `ADUS_PUBLIC_URL`, `ADUS_BIND_ADDR` (default `0.0.0.0:8080`), `ADUS_WORKERS` (default `2`).

## Review Focus

1. **Ganti PAT ke token akun lain / token kedaluwarsa.** Verifikasi gagal → connection `invalid`, repo tidak terhapus, token lama tetap tersimpan. Token akun lain → disimpan, webhook yang hilang dibuat ulang. Test di Task 10.
2. **Delivery webhook duplikat** (GitHub retry, Azure kirim ulang) dan webhook untuk repo yang `enabled=false`/terhapus → tidak ada review ganda; repo nonaktif → 200 tanpa enqueue. Test di Task 19.
3. **Output LLM berantakan:** JSON dibungkus ```` ```json ````, teks pembuka, baris di luar diff, file yang tidak ada → dibersihkan/dibuang, review tetap jalan. Test di Task 20.
4. **Path Azure berawalan `/`** → rule `path_glob = "src/**"` tetap cocok dan komentar Azure tetap ber-`filePath` `/src/...`. Test di Task 9 dan Task 16.
5. **Semua API key kena 429 bersamaan** → job di-retry dengan backoff (bukan langsung `failed`), key pulih setelah `cooldown_until`. Test di Task 13 dan Task 23.

### Task 8: GitHub provider

**Files:**
- Create: `crates/git/src/github.rs`, `tests/fixtures/github/*.json`
- Test: `crates/git/tests/github.rs` (wiremock)

**Interfaces:**
- Produces: `GithubProvider::new(http: reqwest::Client, base_url: String, token: String) -> Self`, implement `GitProvider`.
- Endpoint yang dipakai: `GET /user` (verify; email dari field `email`), `GET /user/repos?per_page=100&affiliation=owner,collaborator,organization_member` (paginasi via header `Link`), `POST /repos/{o}/{r}/hooks` (`{name:"web", active:true, events:["pull_request","issue_comment","pull_request_review_comment"], config:{url, content_type:"json", secret}}`), `GET /repos/{o}/{r}/hooks/{id}` (404 → buat ulang), `DELETE /repos/{o}/{r}/hooks/{id}`, `GET /repos/{o}/{r}/pulls/{n}` (`draft`, `head.sha`, `base.sha` → pakai `merge_base_commit` dari compare `base...head`), `GET /repos/{o}/{r}/pulls/{n}/files?per_page=100` (paginasi, maks 30 halaman = 3000 file), `GET /repos/{o}/{r}/compare/{base}...{head}`, `POST /repos/{o}/{r}/pulls/{n}/reviews` (`{commit_id, event:"COMMENT", body: summary, comments:[{path, line, side:"RIGHT", body}]}`), `POST /repos/{o}/{r}/issues/{n}/comments`.
